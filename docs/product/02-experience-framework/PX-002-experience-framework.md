# PX-002 — Experience Framework

**Document ID:** PX-002
**Title:** Catrack Experience Framework (CEF)
**Status:** Approved
**Version:** 1.0
**Category:** Product Library → Experience Framework

---

# Purpose

Define the experience principles that govern every workflow, screen, workspace, and interaction throughout Catrack.

---

# Principle 1 — Workspace First

Users work within business workspaces, not isolated modules.

Every significant business object should be experienced as a workspace rather than a form.

For Catering ERP, the primary operational workspace is the **Event Workspace**.

---

# Principle 2 — Guide, Don't Train

The application should actively guide users through business processes.

Users should not need to memorize procedures.

Whenever possible, the system should recommend the next logical action.

---

# Principle 3 — Health Before Data

Present operational health before presenting detailed data.

Users should immediately know whether operations are:

* Healthy
* At Risk
* Blocked
* Complete

Detailed information should always support the health indicators.

---

# Principle 4 — Reduce Cognitive Load

The system should remember operational state so users do not have to.

Every feature should reduce:

* Memory burden
* Decision fatigue
* Manual tracking
* Context switching

---

# Principle 5 — Progressive Disclosure

Reveal complexity only when required.

Simple tasks should remain simple.

Advanced information should always be available without overwhelming users.

---

# Principle 6 — Contextual Actions

Every workspace should recommend meaningful next actions based on:

* Current lifecycle stage
* Business rules
* User permissions
* Workflow state

---

# Principle 7 — Business Language

Interfaces should use terminology familiar to catering businesses.

Avoid exposing technical implementation details to end users.

---

# Principle 8 — Minimal Navigation

Users should spend their time completing work rather than searching for screens.

Navigation exists to support work, not define it.

---

# Principle 9 — One Purpose Per Screen

Every screen should have one clear objective.

A user should immediately understand why they are there and what they are expected to accomplish.

---

# Principle 10 — Operational Awareness

The system should always know where the user is within the business process and help them confidently take the next step.
