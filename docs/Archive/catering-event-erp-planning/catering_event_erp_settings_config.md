## 1. Multi-Level Configuration Inheritance

To allow branches, cities, and corporate holding groups to configure the ERP independently, the system uses a **Cascading Override Model**:

```
 [Global Defaults]
         │
         ▼ Override
 [Company Settings]
         │
         ▼ Override
 [Regional Settings (City Hubs)]
         │
         ▼ Override
 [Local Branch Settings]
         │
         ▼ Override
 [User Preferences (Themes / Layouts)]
```

### 1.1. Resolution Mechanism
When a configuration key (e.g., `invoice_prefix`, `mfa_required`) is requested:
1. The system queries the local cache (Redis) for the active user's branch context.
2. If no branch value is set, the system falls back to regional defaults, then company settings, and finally global defaults.
3. If an override is found, the value is returned.

## 2. Document Numbering & Sequence Engine

All critical document numbers (Quotes, Invoices, Purchase Orders, BEOs) are generated by a **Sequence Engine** that supports dynamic formatting and resets:

### 2.1. Numbering Scheme Syntax
Formats are defined using patterns (tokens):
`{BRANCH_CODE}-{DOC_TYPE}-{YEAR}-{SEQUENCE_5_DIGITS}` (e.g., `NY-INV-2026-00045`)

### 2.2. Fiscal Year Resets
* At the start of a new fiscal year (e.g., January 1st or April 1st depending on branch settings), sequences reset to `1`.
* Relational integrity is protected: the database maintains distinct sequences for each combinations of branch, document type, and fiscal year.

## 3. Database Schema Design (16 Tables DDL)

All configuration, numbering, and feature management tables are housed inside the `core` schema.

```sql
CREATE SCHEMA IF NOT EXISTS core;

-- 1. Configuration Categories
CREATE TABLE core.configuration_categories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code VARCHAR(50) NOT NULL UNIQUE, -- e.g. "SECURITY", "KITCHEN", "BILLING"
    name VARCHAR(100) NOT NULL
);

-- 2. Configuration Groups
CREATE TABLE core.configuration_groups (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    category_id UUID NOT NULL REFERENCES core.configuration_categories(id) ON DELETE CASCADE,
    code VARCHAR(50) NOT NULL UNIQUE, -- e.g. "MFA_SETTINGS", "PRICING_POLICES"
    name VARCHAR(100) NOT NULL
);

-- 3. Configurations
CREATE TABLE core.configurations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    group_id UUID NOT NULL REFERENCES core.configuration_groups(id) ON DELETE CASCADE,
    code VARCHAR(100) NOT NULL UNIQUE, -- e.g., "MFA.REQUIRED_FOR_FINANCE"
    name VARCHAR(150) NOT NULL,
    description TEXT,
    data_type VARCHAR(20) NOT NULL DEFAULT 'STRING', -- INT, DECIMAL, STRING, BOOLEAN, JSON
    default_value TEXT NOT NULL,
    is_overridable BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 4. Configuration Versions
CREATE TABLE core.configuration_versions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    configuration_id UUID NOT NULL REFERENCES core.configurations(id) ON DELETE CASCADE,
    version_number INT NOT NULL,
    value_text TEXT NOT NULL,
    effective_start TIMESTAMP WITH TIME ZONE NOT NULL,
    effective_end TIMESTAMP WITH TIME ZONE,
    created_by UUID NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE UNIQUE INDEX idx_config_ver_unique ON core.configuration_versions(configuration_id, version_number);

-- 5. Configuration Values
CREATE TABLE core.configuration_values (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    configuration_id UUID NOT NULL REFERENCES core.configurations(id) ON DELETE CASCADE,
    value_text TEXT NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 6. Configuration Overrides
CREATE TABLE core.configuration_overrides (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    configuration_id UUID NOT NULL REFERENCES core.configurations(id) ON DELETE CASCADE,
    scope_type VARCHAR(20) NOT NULL, -- COMPANY, REGION, CITY, BRANCH, DEPARTMENT, USER
    scope_id UUID NOT NULL, -- Matching Entity ID
    value_text TEXT NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE UNIQUE INDEX idx_config_override_scope ON core.configuration_overrides(configuration_id, scope_type, scope_id);

-- 7. Company Settings
CREATE TABLE core.company_settings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    company_id UUID NOT NULL,
    fiscal_year_start_month INT NOT NULL DEFAULT 1, -- 1 = January, 4 = April
    base_currency_code VARCHAR(3) NOT NULL DEFAULT 'USD',
    branding_logo_path VARCHAR(512),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 8. Branch Settings
CREATE TABLE core.branch_settings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    branch_id UUID NOT NULL,
    timezone VARCHAR(50) NOT NULL DEFAULT 'UTC',
    locale VARCHAR(10) NOT NULL DEFAULT 'en-US',
    operational_start_time TIME NOT NULL DEFAULT '06:00:00',
    operational_end_time TIME NOT NULL DEFAULT '22:00:00',
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 9. Localization Settings
CREATE TABLE core.localization_settings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    company_id UUID NOT NULL,
    locale VARCHAR(10) NOT NULL, -- e.g. "en-US", "es-ES"
    date_format VARCHAR(20) NOT NULL DEFAULT 'YYYY-MM-DD',
    time_format VARCHAR(10) NOT NULL DEFAULT 'HH:mm',
    number_format VARCHAR(20) NOT NULL DEFAULT '1,000.00',
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 10. Number Series
CREATE TABLE core.number_series (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    branch_id UUID NOT NULL,
    document_type VARCHAR(50) NOT NULL, -- INQUIRY, QUOTE, INVOICE, PURCHASE_ORDER
    prefix VARCHAR(20),
    suffix VARCHAR(20),
    next_value INT NOT NULL DEFAULT 1,
    fiscal_year INT NOT NULL,
    pattern VARCHAR(100) NOT NULL, -- e.g. "{PREFIX}-{YEAR}-{SEQ}"
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE UNIQUE INDEX idx_num_series_unique ON core.number_series(branch_id, document_type, fiscal_year);

-- 11. Feature Flags
CREATE TABLE core.feature_flags (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code VARCHAR(100) NOT NULL UNIQUE, -- e.g., "AI_MENU_REC_ENG"
    name VARCHAR(150) NOT NULL,
    is_active BOOLEAN NOT NULL DEFAULT FALSE,
    release_stage VARCHAR(20) NOT NULL DEFAULT 'ALPHA', -- ALPHA, BETA, GA, COMPLETED
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 12. System Policies
CREATE TABLE core.system_policies (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    company_id UUID NOT NULL,
    policy_type VARCHAR(100) NOT NULL, -- PASSWORD_COMPLEXITY, SESSION_TIMEOUT
    policy_parameters JSONB NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 13. User Preferences
CREATE TABLE core.user_preferences (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL UNIQUE,
    theme_preference VARCHAR(20) NOT NULL DEFAULT 'SYSTEM', -- LIGHT, DARK, SYSTEM
    dashboard_layout_json JSONB,
    pinned_menu_items VARCHAR(100)[],
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 14. Theme Configurations
CREATE TABLE core.theme_configurations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    company_id UUID NOT NULL,
    primary_color VARCHAR(7) NOT NULL DEFAULT '#3b82f6', -- Hex colors for white labeling
    secondary_color VARCHAR(7) NOT NULL DEFAULT '#1e293b',
    border_radius_rem NUMERIC(3,2) NOT NULL DEFAULT 0.50,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 15. Import Export Jobs
CREATE TABLE core.import_export_jobs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,
    job_type VARCHAR(20) NOT NULL, -- EXPORT, IMPORT
    entity_name VARCHAR(50) NOT NULL, -- Configurations
    file_path VARCHAR(512),
    status VARCHAR(20) NOT NULL DEFAULT 'PENDING', -- PENDING, RUNNING, COMPLETED, FAILED
    error_message TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 16. Configuration Audit Logs
CREATE TABLE core.configuration_audit_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    table_name VARCHAR(100) NOT NULL, -- e.g., "configuration_overrides"
    record_id UUID NOT NULL,
    action VARCHAR(20) NOT NULL, -- CREATE, UPDATE, DELETE
    old_value_json JSONB,
    new_value_json JSONB,
    changed_by UUID NOT NULL,
    changed_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

## 4. Import & Export Configuration Management

To easily migrate settings between development, staging, and production environments:

* **JSON Configuration Packages:** All database values in the `configurations`, `configuration_overrides`, and `feature_flags` tables can be compiled into a single encrypted JSON file.
* **Environment Imports:** Administrators can upload configuration packages in staging or production. The system runs validation checks on the imported JSON schema before updating the database.
* **Audit History & Rollback:** Every modification to the configuration tables logs the change in `configuration_audit_logs`. If an import causes errors, the administrator can rollback configurations to a previous system snapshot.
