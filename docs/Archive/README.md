# Archive Engineering Documentation

Welcome to the Archive section of the CATRACK Platform Engineering Library.

Nothing here is authoritative. It's preserved for historical reference only — per governance policy, historical material is archived rather than deleted.

## Contents

- **`Migration/`** — artifacts from a prior documentation migration (pre-dates the AG Brain migration below).
- **`superseded-governance-stubs/`** — thin placeholder documents retired during the 2026-07-27 docs/ repository migration (see `docs/project-governance/MIGRATION-LOG.md`) once their real content was moved to `docs/engineering-standards/` and `docs/project-governance/`, or once they were fully superseded by a proper document (e.g. the old `ES-016_AI_Assisted_Engineering_Standard.md` stub, superseded by `docs/engineering-standards/ES-017-...`).
- **`catrack-legacy-planning/`** — platform-wide vision/roadmap/handover documents from the AG Brain historical archive, superseded by what was actually built (`docs/PLATFORM_STATUS.md`, the BWP/EWP backlog) or pending verification against a real current doc (`docs/Deployment/README.md`).
- **`catering-event-erp-planning/`** — an early, much larger (15-module, schema-per-domain) ERP planning effort. Some of it describes the legacy, now-dormant `src/modules/events/` module directly; most describes functionality that was never built at this scope. Kept for historical reference, not as a design target.
- **`engine-runbooks-unbuilt/`** — per-engine technical runbooks for platform engines that were planned but never built (Document, Reporting, Dashboard, Search, Import/Export, Scheduler, and others). Potential seed material for future engine scoping — but any future engine must go through `docs/engineering-standards/ES-015-engine-engineering-lifecycle-standard.md` fresh, not adopt these runbooks as-is.
- **`phase-u-ui-foundation/`** — "Phase U1/U2/U3" compliance reports whose scope doesn't map to any VS-numbered engine or anything else in this repository's governance. Archived pending confirmation this isn't unrelated/abandoned work — see `docs/project-governance/FOLLOW-UP-GOVERNANCE-ITEMS.md` §6.

The full inventory reasoning behind what is and isn't here lives in the migration's Phase 1 record — summarized in `docs/project-governance/MIGRATION-LOG.md`.
